# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Git workflow

- **Never create a git commit without asking first.** Confirm with the user before running `git commit`, even when a change was made at their explicit request.
- **Work directly on `main` for now** (as of 2026-09-23) — no feature-branch/PR workflow currently in use. Commit and push straight to `main` once confirmed. If this changes back to a branch-and-PR flow later, update this file, and go back to asking which branch to commit to and opening (never merging) a PR into `main`.
